2. MOBILDE PROFIL FOTOSU GORUNMEMESININ 7 OLASI NEDENI
===============================================================================

NEDEN 1 — FIRESTORE'DAKI avatar ALANI BASE64 DATAURL, MOBIL URL BEKLIYOR
----------------------------------------------------------------------
    Desktop: avatar = "data:image/png;base64,iVBORw0KGgo..."
    Mobil genelde Coil/Glide ile HTTP URL'leri yukler.
    Coil data URI'leri destekler AMA:
    - Uzun base64 string'ler sorun cikarabilir (256KB+)
    - ImageDecoder bazen "File size limit exceeded" hatasi verir
    - Okuma sirasinda OutOfMemoryError olusabilir

    Cozum A: dataUrl'i dogrudan yukle (en hizli cozum):
      imageView.load(avatarDataUrl) {
          crossfade(true)
          fallback(R.drawable.placeholder_avatar)
      }
      Coil: data URIs'leri "data:" prefix'inden taniyip otomatik cozer.
      Glide: Uri.parse(avatarDataUrl) ile calisir.

    Cozum B (ONERILEN): Desktop'tan avatar'i Firebase Storage'a yukle,
      Firestore'a sadece Storage URL'sini kaydet. Boylece mobil normal
      bir HTTPS URL'si okur. Ama bu BUYUK bir degisiklik gerektirir.

    Cozum C (EN IYISI): Data URL'yi mobile'da decode et, Bitmap'e cevir,
      sonra ImageView'da goster. Coil/Glide otomatik yapar ama manuel:
        val bytes = Base64.decode(avatarDataUrl.substringAfter(","), Base64.DEFAULT)
        val bitmap = BitmapFactory.decodeByteArray(bytes, 0, bytes.size)
        imageView.setImageBitmap(bitmap)

NEDEN 2 — FIRESTORE DOKUMAN BOYUTU SINIRI (1MB)
----------------------------------------------------------------------
    Base64 data URL'ler cok yer kaplar. Ornegin 200KB'lik bir JPEG,
    base64'e cevirince ~267KB olur. Firestore max dokuman boyutu 1MB.
    Bir kullanicinin user dokumaninda avatar (267KB) + diger alanlar
    (username, displayName, bio, publicKey, online, status, lastSeen)
    toplami rahatca 300-400KB'yi bulur.

    Eger birden fazla kullaniciyi batch sorguda cekiyorsaniz, her biri
    300KB+ olabilir. Bu, ag yavaslamasina ve timeout'a yol acar.

    Cozum: Desktop'ta avatar kaydedilirken yeniden boyutlandir (resize).
      su an 5000x5000 cozunurlukte bir fotograf bile dataUrl olarak
      saklanabiliyor. Max 200x200px'e dusurmek base64'i ~20KB'a indirir.

    Mobil tarafta da Coil'in size() fonksiyonu ile yukleme yap:
      imageView.load(avatarDataUrl) {
          size(200, 200)
          crossfade(true)
      }

NEDEN 3 — MOBIL YANLIS ALANI OKUYOR OLABILIR
----------------------------------------------------------------------
    Desktop avatar'i su alanlarda saklar:
      - /users/{uid}.avatar             → base64 dataUrl
      - /friendRequests/{id}.fromAvatar → base64 dataUrl
      - /friendRequests/{id}.toAvatar   → base64 dataUrl
      - /friends/{uid}/list/{fid}.avatar → base64 dataUrl
      - localStorage accounts[i].avatar → base64 dataUrl

    Mobil butun bu kaynaklardan avatar'i OKUYABILMELI:
    - Kendi profil fotosu icin: /users/{myUid}.avatar
    - DM'deki kullanici icin: /users/{peerUid}.avatar
    - Arkadas listesindeki kullanici icin: once friends listesindeki
      avatar'a bak, yoksa /users/{friendUid}.avatar'dan dene
    - Istek listesindeki kullanici icin: fromAvatar/toAvatar

    KONTROL: Mobilde su sorguyu yapip avatar'in geldigini gormelisin:
      FirebaseFirestore.getInstance()
          .collection("users")
          .document(uid)
          .get()
          .addOnSuccessListener { doc ->
              Log.d("Avatar", "avatar field = ${doc.getString("avatar")?.take(50)}...")
              Log.d("Avatar", "avatar length = ${doc.getString("avatar")?.length}")
          }

NEDEN 4 — avatar ALANI null VEYA KISA STRING, FALLBACK GOSTERILMIYOR
----------------------------------------------------------------------
    Desktop'ta avatar null veya tek karakter ise bas harf gosterilir:
      if(c.avatar&&c.avatar.length>2) {
          // img goster
      } else {
          // bas harf goster (c.avatar || _init)
      }
    Mobilde bu fallback KONTROL EDILMELI:
      if (avatarUrl.isNullOrEmpty() || avatarUrl.length <= 2) {
          textView.text = userName.first().uppercase()
          textView.visibility = View.VISIBLE
          imageView.visibility = View.GONE
      } else {
          Coil/Glide ile yukle
      }

NEDEN 5 — FIRESTORE RULES EKSIK (users koleksiyonu)
----------------------------------------------------------------------

    desktop icin calistigini gosterir. ANCAK mobil farkli bir

NEDEN 6 — NETWORK IMAGE LOADER DATA URI'YI DESTEKLEMIYOR
----------------------------------------------------------------------
    Coil ve Glide data URI'lerini destekler ANCAK bazi surumlerde
    sorun olabilir. Ornegin Coil 1.x 'data:' sekmesini otomatik
    algilamaz, Coil 2.x algilar.
    KONTROL:
      - Coil: implementation("io.coil-kt:coil:2.6.0") kullan
      - Glide: implementation("com.github.bumptech.glide:glide:4.16.0")
    Test: Dogrudan bir data URL'sini webview'da acmayi dene:

    Eger webview'da gorunuyorsa Coil/Glide ayarlarinda sorun var.

NEDEN 7 — KENDI PROFIL FOTOMUZ BILE GORUNMUYORSA VERI HIC GELMIYOR
----------------------------------------------------------------------

    Olasiliklar:
    a) Firestore rules /users/{uid} okumayi engelliyor

4. BENIM YORUMUM (Deep)
===============================================================================

"Kendi profil fotomuz dahi gorunmuyor" cumlesi en kritik ipucu.
Bu demek ki Firestore'dan /users/{uid} dokumanina erisimde dahi
sorun var. Cunku kendi UID'mizi biliyoruz, avatar field'ini
okumaya calisiyoruz ama gelmiyor.

Ilk yapman gereken: Firebase Console'u ac, /users/{uid} dokumanina
tikla, "avatar" adinda bir field var mi ve degeri data:... ile
basliyor mu diye kontrol et.

Eger Firestore'da avatar VAR ise:
  -> Sorun mobil okuma katmaninda (Coil ayari, rules)
Eger Firestore'da avatar YOK ise:
  -> Desktop hic avatar kaydetmemis (rules engelledi veya kayit
     sirasinda hata oldu)

En buyuk yapisal sorun: Desktop base64 dataUrl kullaniyor.
Data URL'ler:
- Cok buyuk (Firestore limitine yaklasir)
- Ag uzerinden okumasi yavas (mobilde 500KB indirmek demek)
- Coil/Glide ile sorun cikarabilir
- Cache'lenmesi zor (HTTP ETag vs yok)

ONERILEN UZUN VADELI COZUM:
Desktop'ta avatar'i Firebase Storage'a yukle (kucuk boyutlu),
Firestore'daki avatar alanina Storage URL'sini yaz.
Ornegin: "https://firebasestorage.googleapis.com/v0/b/waxmes...
Bu URL:
- Cok daha kucuk (200 karakter vs 300KB)
- Coil/Glide ile sorunsuz calisir
- Cache'lenebilir (HTTP cache)
- Firebase Storage'in built-in CDN'i ile hizli yuklenir

Ama kisa vadede: Coil'in data URI destegini kontrol et,
gerekirse manuel Base64.decode + BitmapFactory ile coz.

5.4. KESIN COZUM (Story Bar'a Eklenecek Kod)
    Story bar'daki profil dairesi su kaynaklardan OKUMALI:

    1) ONCELIK: storyFeed'deki authorAvatar (story'niz varsa)
    2) SONRA: Firestore user doc'undaki avatar
    3) FALLBACK: kullanici adinin bas harfi

    Kotlin kodu:
      @Composable
      fun MyStoryCircle(
          storyFeed: List<StoryGroup>,
          onClick: () -> Unit
      ) {
          val context = LocalContext.current
          val uid = FirebaseAuth.getInstance().currentUser?.uid
          var firestoreAvatar by remember { mutableStateOf<String?>(null) }

          // Firestore'dan avatar oku
          LaunchedEffect(uid) {
              if (uid != null) {
                  val doc = FirebaseFirestore.getInstance()
                      .collection("users").document(uid).get().await()
                  firestoreAvatar = doc.getString("avatar")
              }
          }

          val myEntry = storyFeed.find { it.isMine }
          val hasStory = myEntry != null

          // Gosterilecek goruntu (oncelik sirasiyla)
          val avatarToShow = when {
              hasStory && !myEntry.items.first().authorAvatar.isNullOrBlank() ->
                  myEntry.items.first().authorAvatar
              firestoreAvatar != null && firestoreAvatar.length > 10 ->
                  firestoreAvatar
              else -> null
          }

          Box(modifier = Modifier.size(56.dp).clip(CircleShape).clickable(onClick = onClick)) {
              if (avatarToShow != null) {
                  // PROFIL FOTOGRAFI
                  AsyncImage(
                      model = avatarToShow,
                      contentDescription = null,
                      modifier = Modifier.fillMaxSize().clip(CircleShape),
                      contentScale = ContentScale.Crop
                  )
                  // Story ring (halka)
                  if (hasStory) {
                      StoryRingCanvas(myEntry.items.size, viewedCount)
                  }
              } else {
                  // FALLBACK: bas harf
                  Box(
                      modifier = Modifier.fillMaxSize()
                          .background(getColorForName(userName)),
                      contentAlignment = Alignment.Center
                  ) {
                      Text(text = userName.first().toString(), fontWeight = Bold)
                  }
                  if (!hasStory) {
                      // + simgesi
                      Icon(Icons.Default.Add, "...", modifier = Modifier.align(BottomEnd))
                  }
              }
          }
      }
